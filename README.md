Ladle & Lantern, an original night-kitchen cooking game: run the line solo, take orders, chop, grill, plate and serve against the clock. Static files, no build step, plays offline in a desktop browser.

## Run it

Serve the game/ folder with any static HTTP server and open game/index.html, or run the hand-in program with Node 22:

```sh
node main.ts
```
